# 性能验证清单

适用于桌面或 Agent 应用的性能排查；具体命令和实现以当前项目为准。

1. 明确慢的操作：冷启动、再次启动、打开长会话、展开工具输出、搜索、后台空闲分别测量。
2. 先记录 CPU、内存、长任务、数据库返回量和请求次数，定位实际路径，避免只凭感觉加缓存。
3. 使用临时目录、隔离配置和合成数据建立基线；不要拿个人会话、凭据或真实配置做破坏性测试。
4. 同一环境、同一数据集比较修改前后，记录预热、重复次数、耗时分布和资源占用。单个组件变快不能推导成整机提速。
5. 验证行为保持：搜索定位、展开状态、取消、重试、时区、并发与关闭清理。
6. 优先删除重复工作，减少不必要的数据传输与渲染；确有主线程长任务时，再考虑有生命周期管理的 Worker。
7. 报告实际执行的检查，分别说明本地通过、CI 通过、合并和发布状态；保留尚未测量的限制。

参考：DeepSeek Harness 的 dsh-speed-up-perf 与 dsh-ci-test-reliability；此清单是跨项目使用的简要整理，详细规则仍以对应项目为准。
